# nasmith.github.io

Source for [Noah A. Smith](https://nasmith.github.io)'s personal/academic website. Built with [Jekyll](https://jekyllrb.com) and hosted on [GitHub Pages](https://pages.github.com), which rebuilds and redeploys automatically on every push to `master`.

## Credits

This site is built on the [academicpages](https://github.com/academicpages/academicpages.github.io) template, created by [Stuart Geiger](https://github.com/staeiou), which is itself a fork of the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) Jekyll theme by [Michael Rose](https://github.com/mmistakes) (© 2016, MIT License — see [LICENSE](LICENSE)). Icon sets vendored under `assets/fonts/` are [Font Awesome](https://fontawesome.com) and [Academicons](https://jpswalsh.github.io/academicons/).

## Local development

The site needs a Ruby that isn't the macOS system Ruby (too old, and on Apple Silicon its native gems are the wrong architecture). This repo is set up to use [rbenv](https://github.com/rbenv/rbenv) with Ruby 3.3.12 (pinned in `.ruby-version`).

One-time setup, if rbenv/Ruby 3.3.12 aren't already installed:

```bash
# install rbenv + ruby-build (see https://github.com/rbenv/rbenv#installation)
rbenv install 3.3.12
```

Then, from the repo root:

```bash
export LANG=en_US.UTF-8   # required - without it, Sass fails on non-ASCII characters
bundle install             # installs gems into vendor/bundle (gitignored)
bundle exec jekyll serve --livereload
```

The site will be at `http://localhost:4000`.

## Adding content

**Talks.** Add a file to `_talks/`, named `YYYY-MM-DD-slug.md`, following the frontmatter pattern of existing entries (`title`, `type`, `permalink`, `venue`, `date`, `location`). The body is a YouTube `<iframe>` embed (or, if the video owner has disabled embedding, a thumbnail `<a>` link to the video instead — see `_talks/2020-07-23-lecture.md`) followed by the talk abstract.

**Publications.** `_pages/publications.md` is generated by an external script (not part of this repo) and pasted in directly — it is not built from a Jekyll collection. (The template's `_publications/` collection and `markdown_generator/` TSV-to-markdown tooling, which shipped with unedited placeholder content, have been removed.)

**Profile photo.** The sidebar picks a random photo on every page load from whatever images are in `images/bio/`. Drop a new photo in that folder (JPEG/PNG, reasonably web-sized — a few hundred KB, not multiple MB) and it's automatically added to the rotation; no code changes needed. See `_includes/author-profile.html` for how this works.

**Favicons / touch icons.** `images/favicon*.png`, `apple-touch-icon-*.png`, `android-chrome-*.png`, `mstile-*.png`, and `favicon.ico` were all generated from a single centered-square crop of the current avatar photo, so they stay visually consistent. If the avatar changes and you want the icons to match, regenerate the whole set from the new photo rather than editing them individually.

## Notes

- `files/` holds PDFs and other downloads linked directly from pages (e.g. `files/challenge.pdf`, linked from `contact.md`). Anything placed here is publicly reachable at `https://nasmith.github.io/files/<name>`, linked or not — treat it as published the moment it's committed.
- `package.json` / the npm `uglify` script is theme build tooling that regenerates `assets/js/main.min.js` from the vendored jQuery plugins under `assets/js/plugins`. It's rarely touched; you only need it if you change those plugin sources.
